# 🛒 MiniStore

MiniStore is a modern e-commerce web app built with React, Redux Toolkit, and Tailwind CSS.

## 🚀 Features
- Product listing with categories
- Live search functionality
- Add to cart / remove items / quantity update
- Cart total calculation
- Login & Signup (localStorage)
- Fully responsive UI

## 🛠️ Tech Stack
React • Redux Toolkit • React Router • Tailwind CSS

## 📌 Purpose
This project is built for learning real-world React e-commerce development.
